About the Simulation

This is an N-Body gravitational simulation using OpenMPI for parallel computation. The simulation calculates the gravitational interactions between multiple bodies in space.

  • Colored circles represent bodies in the simulation
  • Lines show the trajectory of each body
  • The red cross shows the center of mass
Controls Guide
  • Number of Bodies: Adjust the number of objects in the simulation
  • Simulation Speed: Control the playback speed
  • Boundary Size: Set the simulation area size
  • Time Steps: Number of calculation steps
  • Time Delta: Time increment between steps
